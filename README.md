# Inforce Policy Analytics & Simplified Cash Flow Projection with Python

## 📌 Project Overview
This mini project analyzes **inforce insurance policy data** and performs a **simplified cash flow projection** to support actuarial monitoring and reporting activities.
This project is designed as a learning exercise to understand **inforce management, lapse analysis, and basic actuarial projection logic.**

## 🚀 Objectives
- Support **monthly inforce monitoring** through policy status analysis
- Calculate **lapse rate** as a key inforce indicator
- Perform a **simplified projection of premium income and expected claims**
- Apply Python for actuarial data analysis and reporting purposes

## 📊Dataset
This project uses **simulated policy data** generated using Python to represent a simplified insurance portfolio.
### Variables:
- `PolicyID`
- `IssueDate`
- `Age`
- `Premium`
- `SumAssured`
- `Status` (Active/Lapsed)
> ⚠️ This dataset is fully simulated and does not represent real insurance data.

## 📝 Methodology
### Inforce Monitoring
- Policy status distribution (Active/Lapsed)
- Lapse rate calculation
- Policyholder age distribution analysis
### Simplified Actuarial Projection
A high-level projection is performed based on the following assumptions:
- Annual interest rate: **5%**
- Mortality rate: **0.2% per year**
- Projection period: **5 years**
- Projection applies only to **active (inforce) policies**
The projection estimates:
- Discounted premium income
- Expected claims at an aggregate level
> This projection is **simplified** and intended for learning purposes.

## 🛠️ Tools & Technologies
- **Python**
- **pandas** for data processing and analysis
- **numpy** for numerical calculations
- **matplotlib** for data visualization

## 🗝️ Key Outputs
- Policy status summary and lapse rate
- Visualizations of policy distribution and demography
- Simplified estimates of future premium income and expected claims

## 🗝️ Key Takeaways
- Demonstrates understanding of **inforce management and monitoring workflows**
- Applies **basic actuarial reasoning using simplified assumptions**
- Shows the use of Python to support **actuarial reporting and analysis**

## 📊 Key Insights
- Approximately **76.6% of policies remain active**, reflecting the overall stability of the inforce portfolio.
- A **lapse rate of 23.4%** indicates potential risk to future premium income, emphasizing the importance of regular inforce monitoring.
- Premium income is projected to **gradually decrease over time**, primarily due to discounting assumptions.
- Expected claims account for a relatively small proportion of total projected premiums, providing a simplified view of portfolio risk exposure.
